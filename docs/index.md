# Order PySTAC extension

Read and write STAC Order v1.1.0 metadata with `pystac-ext-order`.
The extension supports Items, Collections, Assets, item asset definitions, and Collection status summaries.

- [First steps](tutorials/first-steps.md): create and serialize an Order Item.
- [Install](how-to/install.md): set up the package and documentation tools.
- [Work with Order metadata](how-to/use-extension.md): update fields and summaries.
- [Field reference](reference/fields.md): supported fields and update semantics.
- [Python API](reference/api.md): generated API documentation.
- [Architecture](explanation/architecture.md): storage, registration, and validation.
