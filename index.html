Order PySTAC extension¶

Supported Python versions

Python 3.10 support has been dropped because it reached end of life on October 1, 2026. This package supports Python 3.11–3.15. Please upgrade to a supported version.

Read and write STAC Order v1.1.0 metadata with pystac-ext-order. The extension supports Items, Collections, Assets, item asset definitions, and Collection status summaries.

  • First steps: create and serialize an Order Item.
  • Install: set up the package and documentation tools.
  • Work with Order metadata: update fields and summaries.
  • Field reference: supported fields and update semantics.
  • Python API: generated API documentation.
  • Architecture: storage, registration, and validation.
